# Neon Hand Frame

Frame part of your webcam view with your thumbs and index fingers, and
everything inside turns into a live, shimmering neon visual.

Built with Python, OpenCV and MediaPipe.

## Setup

Requires **Python 3.12**.

```bash
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Run it

```bash
python main.py
```

Hold up both hands with thumbs and index fingers spread, like a photo frame.
Press **Q** to quit.

On a Mac, give VS Code or Terminal **Camera** access in
System Settings → Privacy & Security.
